# 13. Roman to Integer

## Problem
Convert a given Roman numeral string into its corresponding integer representation. Roman numerals are usually written largest to smallest, but smaller values precede larger values to indicate subtraction.

## Example
- **Input:** `s = "MCMXCIV"`
- **Output:** `1994`

## Key Insights
- Subtraction only occurs when a numeral has a strictly smaller value than the numeral directly to its right.
- A single left-to-right pass comparing each element with the next determines whether to add or subtract the current value.
- Using a static hash map or lookup table provides constant-time character-to-value translation.

## Approaches

| Approach | Idea | Time | Space |
| :--- | :--- | :--- | :--- |
| Brute | Replace all 2-character subtractive combinations (e.g., 'IV' -> 'IIII') with standard additive Roman numerals, then sum the values of all characters. | `O(n)` | `O(n)` |
| Optimal | Iterate through the string from left to right, subtracting the current symbol's value if it is smaller than the next symbol's value, otherwise adding it. | `O(n)` | `O(1)` |

## Edge Cases
- Single-character strings (e.g., "I" or "M").
- Strings with purely additive components without subtractive pairs (e.g., "III", "LVIII").
- Strings containing consecutive subtractive pairs (e.g., "MCMXCIV").
- Repeated identical symbols reaching maximum valid length (e.g., "MMMCMXCIX").
