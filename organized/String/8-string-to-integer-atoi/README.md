# 8. String to Integer (atoi)

**Difficulty:** Medium  
**Topics:** String  
**Pattern:** String Parsing

## Problem
Parse a string into a 32-bit signed integer by trimming whitespace, handling an optional sign, and reading contiguous digits. Clamp the result if it exceeds the 32-bit signed integer range.

## Example
- **Input:** `s = "   -042"`
- **Output:** `-42`

## Key Insights
- Processing follows a strict sequential order: leading whitespace, optional sign, contiguous digits, and stopping at the first non-digit character.
- Overflow detection can be handled on the fly using a 64-bit integer (`long`) or by checking `Integer.MAX_VALUE / 10` before multiplying.

## Approaches

| Approach | Idea | Time | Space |
| :--- | :--- | :--- | :--- |
| Brute | Use regular expressions to extract the valid prefix matching whitespace, sign, and digits, then parse the string into an integer while catching overflow exceptions. | `O(n)` | `O(n)` |
| Optimal | Perform a single-pass scan skipping whitespace, recording the sign, and converting character digits iteratively while checking for 32-bit integer boundary overflow. | `O(n)` | `O(1)` |

## Edge Cases
- String with only whitespace or empty string.
- Numbers exceeding 32-bit signed integer bounds (overflow/underflow clamping).
- Extraneous characters appearing before digits (e.g., "words and 987") yielding 0.
- Consecutive signs or invalid sign placements (e.g., "+-12").
