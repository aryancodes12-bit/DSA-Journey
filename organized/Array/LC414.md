# 414. Third Maximum Number

**Difficulty:** Easy  
**Topics:** Array, Sorting  
**Link:** https://leetcode.com/problems/third-maximum-number/

---

## Approach
The solution iterates through the input array to find the top three maximum numbers, utilizing three variables to track these maximums. It skips duplicates by checking if the current number matches any of the existing maximums. The maximums are updated in a cascading manner, shifting the current maximums down when a larger number is found. This approach ensures that the third maximum number is correctly identified, if it exists.

## Complexity
- Time: O(n) because the solution iterates through the input array once, where n is the number of elements in the array.
- Space: O(1) because the solution uses a constant amount of space to store the maximums, regardless of the input size.
