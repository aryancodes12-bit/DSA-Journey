# 1752. Check if Array Is Sorted and Rotated

**Difficulty:** Easy  
**Topics:** Array  
**Link:** https://leetcode.com/problems/check-if-array-is-sorted-and-rotated/

---

## Approach
The solution checks if the input array is sorted and rotated by iterating through the array and counting the number of times an element is greater than the next one. This is done using the modulo operator to wrap around to the start of the array when reaching the end, effectively comparing the last element with the first one. The array is considered sorted and rotated if there is at most one rotation point, i.e., one point where an element is greater than the next one.

## Complexity
- Time: O(n) with a single pass through the array to count rotation points.
- Space: O(1) as it only uses a constant amount of space to store the count of rotation points.
